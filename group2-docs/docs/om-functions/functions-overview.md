OM has 22 functions that can be used to manipulate data each of this functions is categories into 6 categories. There are:

- [**Arithmetic Operation**](/om-functions/arithmetic-operation)
- [**Logic**](/om-functions/logical-operations)
- [**Statistics**](/om-functions/statistics)
- [**Transformation**](/om-functions/transformations)
- [**Utilities**](/om-functions/utilities)
